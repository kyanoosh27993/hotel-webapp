# سیستم جامع حضور و غیاب و حقوق و دستمزد — نسخه ۰.۳.۰

برنامه دسکتاپ ویندوز برای مدیران مالی چندشرکتی — بدون محدودیت در تعداد شرکت و سال مالی.

## راه‌اندازی سریع (ساخت فایل exe)

1. **پایتون ۳.۱۰ یا جدیدتر** را از [python.org](https://www.python.org/downloads/) نصب کنید
   (هنگام نصب حتماً گزینه **Add Python to PATH** را تیک بزنید)
2. پوشه برنامه را باز کنید و روی **`build_exe.bat`** دابل‌کلیک کنید
3. بعد از چند دقیقه، فایل **`PayrollSystem_v0.3.0.exe`** در پوشه «خروجی_برنامه» ساخته می‌شود

> اجرای مستقیم بدون ساخت exe هم ممکن است: `python main.py`

## ورود اولیه

- نام کاربری: `admin`
- رمز عبور: `admin123`
- ⚠️ بعد از اولین ورود، از بخش «مدیریت سیستم ← کاربران» رمز را عوض کنید
- 💡 در هر صفحه **F1** بزنید تا راهنمای کامل همان بخش باز شود (دکمه «راهنمای کامل برنامه» در سایدبار هم هست)

## شروع کار (ترتیب پیشنهادی)

1. **مدیریت سیستم ← شرکت‌ها**: شرکت‌های خود را ثبت کنید (هتل، شرکت، کارگاه — بدون محدودیت)
2. **سال مالی جدید** برای هر شرکت بسازید (۱۴۰۴، ۱۴۰۵، ... بدون محدودیت)
3. **پرسنل**: ثبت دستی یا **ایمپورت اکسل** (فایل «لیست پرسنل این ماه» شما مستقیماً خوانده می‌شود)
   - ⚠️ فیلد **شماره کارت** حیاتی است: تطبیق فایل دستگاه حضور و غیاب با پرسنل از طریق همین فیلد انجام می‌شود
4. **حضور و غیاب**: فایل خروجی دستگاه (گزارش روزانه فردی) را ایمپورت کنید — برنامه خودش ۲۹ شیت را می‌خواند
5. **احکام پرسنلی**: حکم هر پرسنل با تاریخ اجرا ثبت کنید (قابل تغییر هر ماه)
6. **اطلاعات اصلی برنامه**: ساعات موظفی، پله‌های مالیاتی، نرخ‌های بیمه و اقلام فیش — همه قابل ویرایش
7. **حقوق و دستمزد**: دکمه «محاسبه حقوق ماه» → جدول نتایج → خروجی‌ها

## خروجی‌های استاندارد

- 🏦 **لیست بانک و کنترل پرداخت** — انتخاب ردیف‌های پرداختی، ثبت پرداخت، پیگیری مانده حقوق (اکسل + PDF)
- 🧾 **لیست مالیات حقوق (ماده ۹۷)** — اکسل
- 📊 **فایل‌های استاندارد مالیات**: `WPYYYYMM.TXT` (فهرست کارکنان) + `WHYYYYMM.TXT` (فهرست حقوق) طبق راهنمای رسمی سازمان امور مالیاتی نسخه ۱.۷.۰.۴ — بارگذاری در salary.tax.gov.ir (فایل WK در ساختار جدید حذف شده است)
- 🛡 **فایل‌های استاندارد بیمه**: `DSKKAR00.dbf` (کارگاه) + `DSKWOR00.dbf` (بیمه‌شدگان/ریزکارکرد) مطابق نرم‌افزار رسمی «لیست دیسک» — بارگذاری در eservices.tamin.ir + اکسل مرجع ریزکارکرد
- 🛡 لیست بیمه اکسل کامل: سهم کارگر ۷٪ + سهم کارفرما ۲۰٪ + بیکاری ۳٪ + جمع — با درصدهای فردی هر پرسنل
- 📄 **فیش حقوقی PDF** — طراحی رسمی با لوگو و سربرگ شرکت، مانده حقوق ماه قبل، محل امضا، بهینه چاپ سیاه‌وسفید A4
- 📄 **گزارش روزانه فردی حضور و غیاب** — دقیقا مطابق فرمت دستگاه (اکسل + PDF)
- 📤 همه اکسل‌ها با سربرگ رسمی (لوگو + اطلاعات شرکت)، ردیف‌های رنگی، shrink-to-fit و تنظیم چاپ A4

## امکانات کلیدی نسخه ۰.۳

| قابلیت | توضیح |
|---|---|
| شیفت کاری فردی | تعریف شیفت برای هر روز هفته + انتساب ماهانه به هر پرسنل؛ بدون شیفت = ۸ تا ۱۶ عادی |
| تاخیر/تعجیل خودکار | محاسبه از ورود/خروج دستگاه طبق شیفت + **بازه مجاز قابل تنظیم (۰/۵/۱۰ دقیقه...)** |
| مرخصی‌ها | استحقاقی/استعلاجی/بدون حقوق/ساعتی تفکیک می‌شوند؛ استعلاجی پرداختی، بدون حقوق غیرپرداختی |
| ویرایش دستی حضور | ویرایش/حذف هر روز + بازمحاسبه ماه با یک کلیک |
| پرسنل جدید خودکار | فرد ناشناس در فایل دستگاه به‌صورت خودکار «غیرفعال» ثبت و هشدار داده می‌شود |
| بیمه فردی | درصد سهم کارگر/کارفرما/بیکاری برای هر فرد قابل تغییر (پیش‌فرض ۷/۲۰/۳) |
| مانده حقوق ماه قبل | حقوق پرداخت‌نشده به فیش و لیست بانک ماه بعد منتقل و قابل ویرایش است |
| جدول‌های گزارش | فیلتر داخل هدر هر ستون + راست‌کلیک برای نمایش/مخفی کردن ستون + ردیف‌های رنگی |
| راهنمای F1 | راهنمای کامل مو‌به‌مو هر بخش + دفترچه «راهنمای کامل برنامه» (قابل چاپ PDF) |
| لوگو و سربرگ | لوگو و اطلاعات شرکت در همه خروجی‌های اکسل و PDF |
| فرم‌های کیبوردی | جابجایی با Enter/Tab در همه فرم‌ها، اعداد فارسی/انگلیسی |
| تم‌ها | ۶ تم آماده + شخصی‌سازی رنگ‌ها + **فونت‌های نصب‌شده ویندوز** |
| تقویم تا ۱۵۰۰ | کبیسه دقیق + تعطیلات ثابت و قمری (قمری تقریبی ±۱ روز، قابل اصلاح دستی) |

## معماری ماژولار

```
app/
├── main.py                نقطه ورود
├── core/                  هسته (دیتابیس، اعداد، تقویم، امنیت، موتور حقوق، ایمپورت، خروجی‌ها)
├── modules/               (رزرو برای پلاگین‌های آینده)
├── ui/                    رابط کاربری (صفحات، ویجت‌ها، تم)
├── resources/fonts/       فونت وزیرمتن
├── data/                  دیتابیس SQLite (بکاپ = کپی همین فایل)
├── payroll.spec           تنظیمات PyInstaller
└── build_exe.bat          ساخت exe با یک کلیک
```

هر ماژول رجیستری `installed_modules` را در دیتابیس دارد؛ ماژول گزارش‌ساز مستقل است و
قابل جدا‌سازی برای فروش جداگانه.
